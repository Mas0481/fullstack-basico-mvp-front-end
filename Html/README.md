# 👥 Frontend - Cadastro de Funcionários

Interface web desenvolvida para consumir a API de Cadastro de Funcionários, permitindo visualizar e interagir com os recursos disponibilizados pelo backend.

> **Importante:** Para que o frontend funcione corretamente, a API deve estar em execução.

---

## 📋 Pré-requisitos

Antes de iniciar, verifique se:

- A API de Cadastro de Funcionários está executando.
- Um navegador web moderno está instalado (Google Chrome, Microsoft Edge, Mozilla Firefox, etc.).

---

## 🚀 Como executar

### 1. Crie uma pasta para o projeto

Crie uma pasta onde o frontend será armazenado.

Baixe o códifo, você pode obter o código-fonte de duas maneiras.

    ## Opção 1 — Clonar o repositório

    Entre na pasta onde deseja clonar o projeto.
    Clone o repositório.

    ```bash
    git clone hhttps://github.com/Mas0481/fullstack-basico-mvp-front-end

    ```

    ## Opção 2 — Download manual

    1. Acesse o repositório no GitHub:
    https://github.com/Mas0481/fullstack-basico-mvp-front-end
    2. Clique em **Code** → **Download ZIP**.
    3. Extraia os arquivos na pasta criada para o projeto.
    4. Abra a pasta do projeto no Visual Studio Code.

    ---

### 2. Abra a aplicação

Abra o arquivo `index.html` em seu navegador de preferência.

A interface estará pronta para uso, desde que a API esteja em execução.

---

## ⚠️ Observação Importante

O frontend depende diretamente da API para realizar todas as operações.

Caso a API não esteja em execução, funcionalidades como:

- Cadastro de funcionários;
- Consulta de registros;
- Atualização de dados;
- Exclusão de registros;

não estarão disponíveis.

---

## 📖 Documentação da API

A documentação interativa da API está disponível através do Swagger UI.

Acesse:

```text
http://127.0.0.1:5000/docs
```

No Swagger você encontrará:

- ✅ Todas as rotas disponíveis;
- ✅ Métodos HTTP utilizados;
- ✅ Descrição de cada endpoint;
- ✅ Modelos de requisição e resposta;
- ✅ Botão **Try it out**, que permite testar as requisições diretamente pelo navegador.

## 📌 Observações

- Certifique-se de que a API esteja iniciada antes de abrir o frontend.
- Caso a API esteja utilizando outro endereço ou porta, atualize a URL configurada no JavaScript da aplicação.
- Recomenda-se utilizar as versões mais recentes dos navegadores para melhor compatibilidade.
